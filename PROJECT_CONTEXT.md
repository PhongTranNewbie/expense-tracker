# Project Context

## Stack

- Next.js 16
- TypeScript
- Prisma
- Tailwind CSS
- App Router

---

## Project Goals

- Portfolio-quality project
- Beginner maintainable
- Clean and understandable architecture
- Stable and predictable codebase
- Minimal unnecessary complexity

---

## Development Philosophy

- Small scoped changes
- Incremental improvements
- Avoid overengineering
- Prefer readability over cleverness
- Keep the project easy to debug

---

## Preferred Workflow

1. Analyze first
2. Plan implementation
3. List affected files
4. Implement step by step
5. Verify functionality
6. Run build/typecheck

---

## Important Notes

- Preserve current folder structure unless necessary.
- Reuse existing components and utilities whenever possible.
- Avoid massive refactors for small features.
- Focus on maintainability and learning value.
